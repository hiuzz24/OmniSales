🚫 No Lazada sensitive data (buyer name, phone, shipping address) is shared with any third party.
📋 Data Flow Description
Flow From → To Description Security Controls
① Internal User → OSMS Frontend Staff logs in to view/manage orders, products, and inventory. Access requires authentication and role-based authorization. HTTPS/TLS RBAC
② OSMS Frontend → Backend API Frontend sends authenticated API requests (JWT token) to retrieve order details, product data, and manage inventory. HTTPS/TLS JWT Auth
③ Backend API ↔ Lazada API Backend calls Lazada Open Platform APIs to: get order details (buyer name, phone, address), get order items, sync products, sync inventory. Uses App Key + App Secret + seller access token. HTTPS/TLS OAuth 2.0 App Key/Secret
④ Lazada Webhook → Backend API Lazada pushes order event notifications to /api/webhooks/lazada. Backend verifies webhook signature before processing any data. HTTPS/TLS Signature Verify
⑤ Backend API → PostgreSQL Backend stores: orders, order items, buyer name, buyer phone, shipping address, products, inventory levels, synchronization/audit logs, and encrypted access tokens. Only the backend service has database access. Backend-only DB Access Audit Logs
⑥ Seller Center → Lazada API Lazada seller account authorizes OSMS via OAuth 2.0. OSMS receives and securely stores access/refresh tokens for API calls. OAuth 2.0

🛡️ Security Controls Summary
🔒
HTTPS/TLS Encryption
All data in transit encrypted. Frontend ↔ Backend, Backend ↔ Lazada API, Webhook endpoints.
🔑
Backend-only Secret Storage
App Secret, access tokens, and refresh tokens stored only in backend database. Never exposed to frontend.
👥
Role-Based Access Control (RBAC)
Internal users require login + role authorization to view order details containing sensitive buyer data.
🗄️
Database Access Restriction
PostgreSQL database is only accessible by the backend service. No direct external database access.
✅
Webhook Signature Verification
All incoming Lazada webhook requests are verified by signature before processing to prevent spoofing.
📝
Audit & Sync Logs
All webhook events, API sync operations, and data changes are logged for traceability and debugging.
🚫
No Third-Party Data Sharing
Lazada buyer data (name, phone, address) is never shared with third parties. Data flows only between OSMS and Lazada.
🏠
Internal System Only
OSMS is an internal seller management system. Not a public marketplace app. No external user registration.
